# Mobile stack

Мобильное приложение **пока не разрабатывается**.

`packages/mobile/` в репо — пустая директория без файлов. Никакого кода там нет.

Когда дойдёт до мобилки — стек будет определён отдельно (предположительно Kotlin Multiplatform + Compose Multiplatform, но это не зафиксировано).

**До запуска мобильной разработки:**
- Не создавать задачи с `task.type = frontend_mobile`
- CTO должен явно отклонять такие декомпозиции
- Агенты не работают в `packages/mobile/`
