# moy-kosmetolog — Product Context

## Что это

moy-kosmetolog — мобильное приложение и PWA для записи к косметологу.
Целевая аудитория: клиенты косметологических кабинетов (в основном женщины 25–45).

## Ключевые ценности продукта

- **Простота**: пользователь должен записаться в 2–3 тапа, не разбираясь в интерфейсе
- **Доверие**: внешний вид и тексты создают ощущение профессионального, тёплого сервиса
- **Скорость**: ни один экран не должен грузиться дольше 1.5 секунд на среднем телефоне

## Стек (кратко)

- Backend: Python (FastAPI + SQLAlchemy), PostgreSQL
- PWA: Next.js 14 (App Router), Tailwind CSS, shadcn/ui (halo-ds)
- Mobile: React Native (Expo), NativeWind

## Дизайн-система

Используется `halo-ds` — внутренняя дизайн-система поверх shadcn/ui.
Компоненты: `packages/web/components/ui/`. Не выдумывай новые имена компонентов — проверь что уже есть.

## Что важно для всех агентов

- Все пользовательские тексты на **русском** языке
- Мобильная версия — приоритет (mobile-first)
- Изменения должны быть минимально-инвазивными: не ломай существующий UX
- Если не уверен что компонент/эндпоинт существует — проверь в коде перед тем как выдумывать
